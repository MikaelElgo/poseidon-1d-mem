## Corrections completed

1. The high shallow-column scenario now consumes the same well's P05 calculated over
   `eligible_for_measured_integration`, not P05 over all finite density. The two
   populations are separately named and exported.
2. Public gap-threshold overrides and all threshold-bearing records now reject boolean,
   textual, complex, negative, NaN and infinite values with typed errors. Positive
   infinity can no longer make every gap bridgeable.
3. Scenario accounting now partitions every total into assumed, conditioned and strictly
   measured fractions. Constructor invariants require each component in `[0, 1]` and the
   three-component sum to equal one.
4. Locked seabed ingestion now fails closed on a missing table and malformed, duplicate
   or non-finite matching rows. A valid header-only table remains a valid explicit empty
   mapping.
5. Default JSON export now writes explicit UTF-8 LF bytes, eliminating host-dependent
   newline translation.

All five baseline behaviors were reproduced before correction. One proposed additional
rule—exact equality of locked seabed MDRT and survey TVD—was rejected during the build
because it produced a false positive on Boreas 1's 0.0000114393325 m interpolation-level
difference. That rule is not in the release; a regression test preserves the valid locked
record.
