# Intentional self-exclusion (this file only): a checksum file cannot
# contain the SHA-256 of its own final on-disk bytes, because writing

#

# computed and embedded into that same file, is impossible; the
# checksum of a different, already-finished file is ordinary and is
# listed below like any other packaged file.
